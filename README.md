# Stockly Prototype

Prototype mobile interactif (HTML/CSS/JS) pour démontrer les 9 écrans clés de Stockly.

## Lancer localement

```bash
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

## Parcours de démo rapide

1. Ouvrir l'écran Connexion.
2. Choisir le rôle `Propriétaire` ou `Vendeuse`.
3. Cliquer sur **Se connecter**.
4. Aller sur **Vente** et confirmer une vente.
5. Vérifier les mises à jour dans **Journal** et **Alertes**.
